# TikTok Shop VN · Gia dụng

> Phase: **0 · Nghiên cứu** · Cập nhật: 2026-10-10

## Mục tiêu
- Xây kênh affiliate TikTok Shop Việt Nam ngành **gia dụng**, kiếm hoa hồng qua **video ngắn** và **livestream**.
- Nguồn video: nội dung sản phẩm từ Trung Quốc (Douyin, Xiaohongshu, Kuaishou, video sản phẩm 1688/Taobao),
  **biên tập lại + Việt hoá** để đảm bảo tính nguyên bản, khớp với sản phẩm đang bán trên TikTok Shop VN.

## KPI (đề xuất — chốt sau Phase 0)
| Chỉ số | Mục tiêu 30 ngày | Mục tiêu 90 ngày | Hiện tại |
|--------|------------------|------------------|----------|
| Video đã đăng | 60 (2/ngày) | 270 (3/ngày) | 0 |
| Follower | 1.000 | 10.000 | 0 |
| Đơn affiliate / tháng | 30 | 500 | 0 |
| Hoa hồng / tháng (VNĐ) | 1 triệu | 15 triệu | 0 |
| Phiên livestream / tuần | 0 | 3 | 0 |

## Lộ trình
- [ ] Phase 0 — Điều kiện affiliate/live, ngách con, đối thủ, nguồn video, chính sách nguyên bản ([RESEARCH-PLAN](research/RESEARCH-PLAN.md))
- [ ] Phase 1 — Test thủ công: 30–60 video, 2–3 kiểu biên tập, 10–20 sản phẩm
- [ ] Phase 2 — Chuẩn hoá: săn sản phẩm → tìm video nguồn → Việt hoá → đăng → gắn giỏ hàng thành skill
- [ ] Phase 3 — Bán tự động + bắt đầu livestream
- [ ] Phase 4 — Nhân rộng nhiều tài khoản/ngách con

## Pipeline mục tiêu
```
Săn sản phẩm bán chạy (TikTok Shop / Kalodata / FastMoss) → Tìm video gốc TQ cùng sản phẩm (Douyin/1688)
→ Tải không watermark → Biên tập lại (cắt, đổi nhịp, thêm cảnh, phụ đề + giọng Việt, hook mới)
→ Đăng + gắn link sản phẩm → Theo dõi view/click/đơn → Nhân bản sản phẩm/format thắng
```
