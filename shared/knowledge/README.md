# Kiến thức dùng chung

Chỉ chứa kiến thức đúng cho **nhiều dự án**. Mỗi khẳng định ghi ngày + nguồn; chưa chắc → `[CẦN XÁC MINH]`.

- `platforms/` — chính sách, thuật toán, giới hạn của từng nền tảng
- `tools/` — danh mục tool bên ngoài: dùng cho gì, giá, API, dự án nào đang dùng
- `vietnam-legal-tax.md` — thuế & pháp lý VN (thuế thu nhập nền tảng nước ngoài, luật quảng cáo, chứng khoán, crypto)
- `lessons.md` — bài học xuyên dự án
