# Pinterest — kiến thức nền tảng

> Cập nhật lần cuối: 2026-10-10. Dùng bởi: 03.

- Cho phép link affiliate trực tiếp trên pin (phải công bố; không dùng link rút gọn che đích) `[CẦN XÁC MINH quy định hiện hành]`.
- Pinterest hoạt động như công cụ tìm kiếm hình ảnh: từ khoá trong tiêu đề/mô tả/board quan trọng; pin có vòng đời dài.
- Tài khoản mới đăng nhiều link cùng domain dễ bị gắn spam — tăng tần suất dần `[CẦN XÁC MINH ngưỡng an toàn]`.
- Có API chính thức để tạo pin (cần app được duyệt).
